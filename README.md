# Онлайн-экзамен

Тесты с таймером, письменные работы (writing), очередь на speaking и ведомость. Работает на чистом Node.js, внешние зависимости не нужны.

## Запуск

Нужен Node.js 18 или новее.

```bash
node server.js
```

Сайт откроется по адресу http://localhost:3000.

## Предметы и базовые экзамены

- 4 предмета со своим цветом: Высшая математика (индиго), Казахский язык (янтарный), Английский язык (красный), Микробиология (зелёный).
- У студента в разделе «Экзамен» — вкладки по предметам; карточка экзамена: шапка в цвете предмета с названием, обложка и круглая кнопка «Выполнить» в цвете темы из настроек (по умолчанию бирюзовая). Подробности (преподаватель, число заданий, время, срок, статус) — на странице экзамена.
- 16 базовых экзаменов (по 4 на предмет, уровень 1 курса) сделаны в формате редактора (`exam-builder/1`): их можно открыть, изменить, скопировать, экспортировать в Word и опубликовать заново. Опубликованы бессрочно для всех студентов.
- Перед публикацией к экзамену можно прикрепить обложку (карточка «Обложка для студентов» в публикации); картинка обрезается до 16:9 и уменьшается до 640×360. При новой публикации того же экзамена обложка подставляется из прежней.
- При первом запуске новой версии сервер один раз переводит базу на схему 2: удаляет все прежние экзамены, публикации и работы по ним и добавляет базовые экзамены из `exam-sync/base-exams.json`. Пересобрать этот файл: `node tools/make-base-exams.js [covers.json]`.
- Фото обложек — Wikimedia Commons, свободные лицензии (Public domain, CC0, CC BY, CC BY-SA); автор, лицензия и ссылка лежат в поле `coverCredit` каждого базового экзамена.

## Возможности

- **Преподаватель:** конструктор тестов (5 видов заданий: «Да / Нет»; выбор одного или нескольких ответов; сопоставление слов, картинок или голосовых — голос можно записать прямо в браузере; пропуски в тексте; составление предложения из слов или слова из букв), комнаты экзамена (тест + writing + speaking) с пошаговым выбором аудитории (направление → курс → группы; экзамен видят только выбранные студенты), длительность экзамена по минутам или по дням (после срока экзамен исчезает у студентов), очередь на speaking, проверка работ, лист баллов по выбранному экзамену (студенты экзамена, оценённые работы, ожидающие проверки).
- **Меню преподавателя — 4 вкладки:**
  - **Задания для студентов** — что, кому и на какой срок выдано, очередь на спикинг, кто вышел во время экзамена.
  - **Опубликовать экзамен** — выбор готового экзамена (созданного или загруженного из Word), правка его заданий, баллов и порядка прямо перед публикацией, группы (направление → курс → группы), начало и длительность, баллы по навыкам (по умолчанию 100 делятся поровну между навыками экзамена) и порядок спикинга: в любое время, сначала спикинг или после теста и письма. Здесь же список опубликованных.
  - **Редактор** — слева все экзамены преподавателя, справа редактор: 5 разделов (тест, чтение, аудирование, письмо, говорение), все виды заданий, картинки и аудио, импорт .docx с отчётом, экспорт в Word (с ответами и без), HTML-тест, проект .json, предпросмотр.
  - **Баллы** — лист баллов по навыкам (тест, чтение, аудирование, письмо, спикинг) с поиском студента по имени, фамилии или логину.
- Баллы за тест, чтение и аудирование считаются автоматически по доле правильных ответов в своём разделе; преподаватель подтверждает или меняет их на странице проверки.
- **Студент:** экзамены своей группы с обратным отсчётом оставшегося времени, тесты с таймером, writing, запись на speaking, результаты, карточки для повторения слов. Когда срок экзамена выходит, незавершённый тест и начатая письменная работа сдаются автоматически.
- Время теста и письменной работы с лимитом идёт, даже если студент вышел или закрыл вкладку; преподаватель получает уведомление и может остановить время.
- После завершения speaking сразу открывается окно оценки за speaking.
- Изменения синхронизируются между всеми открытыми вкладками и устройствами в реальном времени.

## Настройки

Шестерёнка или аватар в верхней панели → «Настройки»:

- **Оформление:** цвет (inCampus, University of Arizona, изумрудный, фиолетовый, коралловый, графит, розовый), тема (авто / светлая / тёмная / как в системе), размер текста, высокая контрастность, меньше анимации;
- **Язык:** RU / EN / KZ;
- **Уведомления:** звук и вибрация при вызове на speaking, уведомление о начале экзамена по расписанию, уведомления браузера;
- **Экзамен:** показывать таймер, подтверждать отправку теста;
- **Аккаунт:** смена пароля, выход.

## Устройство

- `server.js` — HTTP-сервер.
- `exam-sync/eb/` — ядро конструктора экзаменов: модель, импорт/экспорт .docx, JSZip 3.10.1 (MIT), плеер для HTML-экспорта, демо-экзамен; `model.js` грузится сразу, остальное — по требованию.
- `exam-sync/index.html` — интерфейс, `exam-sync/handler.js` — сервер синхронизации, `exam-sync/seed.json` — начальные данные, `exam-sync/base-exams.json` — 16 базовых экзаменов с обложками.
- `tools/make-base-exams.js` — генератор базовых экзаменов.
- `data/exam-sync.json` — данные экзаменов (создаётся автоматически, не в git).
- `deploy/alwaysdata-update.sh` — автообновление сервера на alwaysdata.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `IP` | все интерфейсы | IP для прослушивания |
| `EXAM_MAX_BODY_MB` | `32` | Предельный размер одного запроса синхронизации (экзамены с картинками и аудио) |
