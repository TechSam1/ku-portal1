# Онлайн-экзамен

Тесты с таймером, письменные работы (writing), очередь на speaking и ведомость. Работает на чистом Node.js, внешние зависимости не нужны.

## Запуск

Нужен Node.js 18 или новее.

```bash
node server.js
```

Сайт откроется по адресу http://localhost:3000.

## Аккаунты

| Роль | Логин | Пароль |
|---|---|---|
| Студент | `user`, `user1`–`user4` | `1` |
| Преподаватель | `teacher` | `admin` |

## Возможности

- **Преподаватель:** редактор тестов, комнаты экзамена (тест + writing + speaking), очередь на speaking, проверка работ, ведомость.
- **Студент:** тесты с таймером, writing, запись на speaking, результаты, карточки для повторения слов.
- Время теста и письменной работы с лимитом идёт, даже если студент вышел или закрыл вкладку; преподаватель получает уведомление и может остановить время.
- После завершения speaking сразу открывается окно оценки за speaking.
- Изменения синхронизируются между всеми открытыми вкладками и устройствами в реальном времени.

## Настройки

Шестерёнка или аватар в верхней панели → «Настройки»:

- **Оформление:** цвет (inCampus, University of Arizona, изумрудный, фиолетовый, коралловый, графит, розовый), тема (авто / светлая / тёмная / как в системе), размер текста, высокая контрастность, меньше анимации;
- **Язык:** RU / EN / KZ;
- **Уведомления:** звук и вибрация при вызове на speaking, уведомление об открытии экзамена, уведомления браузера;
- **Экзамен:** показывать таймер, подтверждать отправку теста;
- **Аккаунт:** смена пароля, выход.

## Устройство

- `server.js` — HTTP-сервер.
- `exam-sync/index.html` — интерфейс, `exam-sync/handler.js` — сервер синхронизации, `exam-sync/seed.json` — демо-данные.
- `data/exam-sync.json` — данные экзаменов (создаётся автоматически, не в git).
- `deploy/alwaysdata-update.sh` — автообновление сервера на alwaysdata.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `IP` | все интерфейсы | IP для прослушивания |
